**<h1>Nexis Global Sales Dashboard</h1>**

A visually focused Power BI dashboard built to practice interactive layout, theming and dashboard design.

https://github.com/user-attachments/assets/78fffeff-7286-4d67-8cca-69df75d3670a

## About the Data

This dashboard uses sales data for Nexis Global, a fictional company selling Office Supplies, Furniture and Technology products across North and South America — covering revenue, profit and product performance by segment and category.

## What This Project Covers

- Cleaned and prepared raw sales data for use in Power BI
- Designed a dark themed, KPI driven dashboard layout
- Built interactive region filtering using custom toggle buttons instead of default slicers
- Visualized revenue, profit, units sold and top/bottom performing products across time, segment and category

## Tools Used
Power BI Desktop, Data Cleaning
